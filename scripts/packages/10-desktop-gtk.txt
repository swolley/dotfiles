# The GTK applications I use every day. The session is niri only: gnome-shell
# and gdm are gone (they are in rimuovi.txt), login is handled by greetd with
# noctalia-greeter. These programs do not depend on the shell, only on the
# libraries, and keep working exactly the same.
#
# No gnome-control-center or gnome-tweaks: settings are managed by
# noctalia, and whatever is left can be changed with gsettings.
nautilus
sushi
gnome-text-editor
gnome-calculator
# gnome-disk-utility: SMART health, benchmarks, writing images to USB
# sticks, mount options. Works on live systems, through udisks.
gnome-disk-utility
# gparted: the other half of the job, the one Disks does not do. Moves and
# resizes partitions, queuing the operations.
#
# Its stock launcher elevates with pkexec and ends up on xwayland, where
# menus get truncated and the theme goes back to light. It is replaced by the
# launcher in applications/.local/share/applications/gparted-wayland, which
# passes the wayland socket to root. So no xorg-xhost: only the old way needed it.
gparted
gnome-keyring
seahorse
file-roller
loupe
# papers is the GNOME document viewer, successor to evince
papers
totem
gvfs
gvfs-afc
gvfs-gphoto2
gvfs-mtp
gvfs-nfs
gvfs-smb
xdg-desktop-portal
xdg-desktop-portal-gnome
xdg-user-dirs
xdg-user-dirs-gtk
xdg-utils
adwaita-icon-theme
gnome-themes-extra
cantarell-fonts
power-profiles-daemon
network-manager-applet
networkmanager
# VPN: OpenVPN for work; WireGuard is native in NetworkManager,
# wireguard-tools provides wg and wg-quick on the command line
networkmanager-openvpn
wireguard-tools
